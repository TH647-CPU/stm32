# 20mA~200mA 恒流 LED 控制程序（STM32F103C8 / HAL 库）

基于原有 `bsp_pwm / bsp_adc / bsp_light` 补齐按键控制，当前固件实现：

- 5V 输入、恒流输出 **20mA~200mA**（运放恒流源 + Rsense 采样）
- **PWM 调光**（PA0/TIM2_CH1，ARR=999，约 111Hz）
- **ADC 实时采样电流**（PA2/ADC2）
- **光敏传感器**（PA1/ADC1）自动调明暗
- **3 个外部按键**控制开关 / 模式 / 亮度档位

---

## 一、按键布局（当前固件）

| 按键 | 引脚 | 功能 |
|------|------|------|
| **开关** | **PB12** | 切换输出 开 / 关（默认上电开） |
| **转换** | **PB13** | 手动调光 ↔ 自动光控 二选一切换 |
| **档位** | **PB14** | 单键循环 4 档亮度 |

**档位循环**（KEY_DIM 每按一次跳一档）：`100%(最亮) → 75%(较亮) → 50%(中等) → 25%(暗) → 100% …`

上电默认第 1 档 **100%（最亮）**。档位表在 `key_app.c` 的 `ka_step_tbl[4] = {100, 75, 50, 25}`，想改亮灭幅度直接改这里。

按键为**低电平有效**（内部上拉，按下接地 GND）。判断按键是否正常：未按时引脚应量到约 **3.3V**，按下约 **0V**（是量电压，不是量电流——输入口高阻，量电流无意义）。

## 二、文件清单

| 文件 | 作用 |
|------|------|
| `bsp_key.h/.c` | **3 键**扫描（PB12/PB13/PB14），消抖 + 按下沿 + 长按连发 |
| `key_app.h/.c` | 按键处理主程序：开关 / 手动↔自动光控 / 单键循环档位 |
| `bsp_display.h/.c` | 4 位 7 段数码管 GPIO 动态扫描，引脚宏可配（驱动已就绪，见“状态”） |
| `bsp_led.h/.c` | 恒流闭环：目标电流 + ADC2 采样 + PI 输出 PWM（见“状态”） |
| `bsp_pwm / bsp_adc / bsp_light` | 原有外设：PWM 输出 / ADC 采样 / 光感滤波映射 |
| `Core\Src\main.c` | 入口：`KEY_AppInit()` + 主循环 `KEY_AppHandle()` |

`app.c/.h` 为旧 4 键状态机，**已弃用**（不在编译列表，勿加回工程）。

## 三、接线（外部器件）

```
【恒流驱动】 5V ── LED(串) ── D N-MOS ── S ── Rsense(10Ω) ── GND
                  │            │ G
                  │            └── 运放输出（LM358 等）
    PA0 PWM ── RC滤波 ── Vset ── 运放 +
                  运放 - ── Vsense(Rsense 上端) ── PA2(ADC2_IN2)
```
运放强制 `Vsense = Vset`，故 `I = Vset / Rsense`，PWM 占空比决定 Vset 即决定电流。

```
【光敏】  光敏电阻(或光敏二极管+电阻分压) ── PA1(ADC1_IN1)
【按键】  PB12、PB13、PB14 ── 各接一个按键到 GND（低有效，内部上拉）
【数码管】段码 a~g,dp → PB0 PB1 PB8 PB9 PB12 PB13 PB14 PB15
          位选 0~3     → PC13 PC14 PC15 PA9
```
> 数码管与按键引脚全部在头文件里用宏定义（`bsp_display.h`、`bsp_key.c`），按实际接线改即可。

**若要启用数码管显示电流**：在 `KEY_AppHandle()` 主循环里周期调用 `DISP_Show...`，把 `KEYAPP_GetBrightness()` / ADC 采到的电流换算后刷到数码管。
**若要启用恒流闭环**：给一个按键或固定把 `ka_dim_mode` 置 1，并确保 20ms 调一次 `LED_ControlTick()`。

## 五、关键参数调整（都在对应 .h/.c 顶部）

- **亮度档位**：`key_app.c` 的 `ka_step_tbl[4] = {100,75,50,25}`
- **电流范围**：`bsp_led.h` 的 `LED_CUR_MIN_MA / LED_CUR_MAX_MA`（默认 20/200mA）
- **采样电阻**：`bsp_led.h` 的 `LED_RSENSE_OHM`（默认 10Ω），务必与硬件一致
- **恒流闭环**：`bsp_led.h` 的 `LED_CLOSED_LOOP_ENABLE`、`LED_PI_KP / LED_PI_KI`
- **自动光控极性**：`key_app.c` / `bsp_light.c` 的映射表与反相开关
- **数码管类型/引脚**：`bsp_display.h` 顶部宏

## 六、注意事项

- **数码管段码 PB12/13/14 与按键 PB12/13/14 冲突**：若启用数码管显示，必须改 `bsp_display.h` 的段码引脚避开按键（或换按键引脚），否则会互相覆盖配置导致按键或显示异常。
- 系统时钟为 **8MHz HSI**（无 PLL），TIM2 输出约 **111Hz**，RC 滤波须滤掉该频率。
- 共阳数码管请在 `bsp_display.h` 把 `DISP_COMMON_CATHODE` 改为 0 并核对位选电平。
- 按键初始化已做“读实际电平作为初值”修复，上电不会因引脚低电平误触发按键动作。
